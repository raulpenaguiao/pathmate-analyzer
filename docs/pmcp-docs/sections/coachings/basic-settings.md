# Basic Settings and Modules

Source: https://my.pathmate.app/pmcp-documentation/doc-6-0/sections/coachings/basic-settings · fetched 2026-09-29 · condensed extract

**Both the Coaching and Monitoring must be deactivated before editing basic settings.**

- **General:** the sender id for SMS; *Automatically finish unfinished screening surveys* (fills in defaults); dashboard enabled / template path / password expression; Deepstream client access password.
- **Languages:** available vs active languages. The **first active language is the default**.
- **Version control:** minimal app version required for an update; the coaching to update to.
- **Email templates:** token request, registration attempt, password reset, password changed, email changed, header, footer.
- **Automatic deactivation:** after **186 days** of inactivity, with warning messages sent 1 month, 1 week and 1 day before, and on the day.
- **Monitoring:** *monitoring starting days* (the weekdays new users start); *coachings to involve in uniqueness checks*.
- **LLM settings:** four meta blocks, all accepting variables: About the Coaching, About the Form of Speech, About the Coach, About the Participant.
- Language and LLM changes "significantly affect user experience and require careful testing before reactivation".
