# Designing Coaching Dialogues

Source: https://my.pathmate.app/pmcp-documentation/doc-6-0/best-practices/designing-dialogues · fetched 2026-09-29 · condensed extract

- **Clarity:** simple language; one idea per message; minimal filler.
- **Length:** 2–3 sentences (~200 characters) per message. **Max session 10 minutes.** The coach sends **no more than 3 messages before prompting a user response**.
- **Expectation management:** say how long an interaction will take (especially over 3–5 min), and give verbal progress ("We've already reached the last question for today.").
- **Tone:** natural, friendly but competent. Address the user directly and by name.
- **Emojis:** for a friendly tone, to highlight information, used consistently per function (💊 medication, 📘 diary…), and topic-related.
- **Images:** to engage, illustrate concepts and break up text.
