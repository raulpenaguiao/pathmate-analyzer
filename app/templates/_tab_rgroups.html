Grows the thin r_* randomisation pools in this coaching's attached coaching.json, in three steps. A fourth step writes the new variants into the live editor and needs a browser, so it stays a CLI tool: tools/rgroups-table/rgroup_apply.py --limit N --apply.

1. Build the table

One row per r_*-tagged message, with its pool, variant count and text.

2. Prepare the request manifest

One row per thin pool (fewer than 10 distinct variants) — no prompt text yet, no API calls.

3. Generate variants with an LLM

Calls the provider's API once per thin pool, up to the limit below. The key is used only for this run — it is never written to disk.
